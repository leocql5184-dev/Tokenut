# Tokenut

一个会随 Token 用量进化的 Windows 桌面伙伴。

## **向孙哥（孙宇晨）的目标对标：每天一亿 Token！**

**项目灵感来自孙哥（孙宇晨）提出的「每天一亿 Token」目标。** 我们向这个目标对标，把每天的使用量变成看得见的充能进度和角色变化。

## 下载与使用

1. 打开本仓库的 **Releases（发行版）**，下载 `Tokenut-版本号-Windows-x64.zip`。
2. **完整解压**，打开文件夹，双击 `Tokenut.exe`。不要只拿出 EXE，也不要在压缩包里直接运行。
3. 首次启动会打开连接页面。先在本机 Codex 登录并完成一次对话，看到 **Codex 已连接** 就可以使用。Tokenut 每 **5 秒**自动更新。

**不需要安装 Node.js、不需要填写 API Key、不需要配置端口，也不需要把账号密码交给 Tokenut。** 当前支持 Windows x64。

首次没有数据时，先在 Codex 中完成一次对话，再稍等片刻。更新取决于 Codex 何时写入用量记录。

## 怎么操作

| 操作 | 功能 |
| --- | --- |
| 点击角色 | 打开每日用量折线图 |
| 按住角色拖动 | 移动桌面组件 |
| 右键角色或点击「···」 | 预览形态、调整大小和置顶、减少动画、退出 |
| 点击同步按钮 | 立即读取最新记录 |
| 关闭折线图窗口 | 桌面组件继续记录 |

折线图支持 **近7天、近1月、近3月、近6月**。今天持续更新，北京时间每天 **00:00 归档前一天**，历史记录保存在本机。

## 如何连接自己的 Codex

首次打开时，程序会自动查找本机 Codex 记录。**显示“Codex 已连接”就不用设置了。**

找不到时只需：

1. 先打开本机 Codex，登录自己的账号并完成一次对话。
2. 回到 Tokenut，点击 **自动检测**。
3. 仍未连接，点击 **选择记录文件夹**，选择 Codex 的 `sessions` 文件夹或它的上级 `.codex` 文件夹。程序会记住，下次自动连接。

默认文件夹位于 `C:\Users\你的用户名\.codex\sessions`。使用自定义位置时，直接通过按钮选择即可，无需修改代码或环境变量。选择了空目录时会明确提示“暂未发现会话”，不会把它误报成有数据。

已经使用过的用户可以点击角色，在客户端顶部更改连接目录；切换目录时分别保留各来源的历史，不把不同目录的统计直接混加。

只统计**当前 Windows 用户的本机 Codex 会话记录**，不调用模型，不上传会话内容。不是账号账单：不包含其他设备，同一系统用户下切换 Codex 账号也可能一起计入。

## 常见问题

**没有用量？** 确认本机已使用过 Codex、上述目录内有记录，然后点击「立即同步 Codex」。只有网页或其他设备上的记录不会出现。Codex 日志格式变化可能需要更新本软件。

**关机后怎么办？** 退出或关机时不运行。重启后从仍存在的日志补回可读取记录；删除、缺失或移到其他归档目录的日志可能无法补全。无记录日期留空，不假装是零。

**数据在哪？** 通常在 `%APPDATA%\tokenut\usage.json`，包含每日汇总和设置。更新程序不主动删除数据；请勿公开上传此文件。

**Windows 安全提示？** 当前程序未做代码签名。请确认下载来源可信，可用随版本提供的 `.sha256` 校验包文件，不要关闭系统安全保护。
